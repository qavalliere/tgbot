# 🤖 Telegram-бот для малого бизнеса (генератор заявок / лидов)

Готовый и надежный Telegram-бот для малого бизнеса (салоны красоты, барбершопы, мастерские, консультации, клиники и др.).

Работает на **Python 3.12+ (aiogram 3.x)** с асинхронной базой данных **SQLite (aiosqlite)**.

> ⚡ **Ищете версию на Node.js (Telegraf 4.x)?** Она доступна в ветке [`node-js`](https://github.com/qavalliere/tgbot/tree/node-js).

---

## 🚀 Возможности

1. **Главное меню (`/start`)**:
   - `📋 Оставить заявку`
   - `💰 Услуги`
   - `📍 Контакты`
2. **Прайс-лист (`💰 Услуги`)**: Список услуг с ценами и кнопка быстрого перехода к заявке.
3. **Контакты (`📍 Контакты`)**: Адрес, телефон, график работы.
4. **Пошаговое оформление заявки (FSM)**:
   - Шаг 1: Имя клиента.
   - Шаг 2: Номер телефона (ввод вручную с валидацией формата или кнопка «📱 Поделиться контактом»).
   - Шаг 3: Выбор услуги (динамические кнопки из `SERVICES` + «Другая услуга»).
   - Шаг 4: Желаемое время и дата.
   - Шаг 5: Проверка данных и подтверждение (`✅ Отправить` / `❌ Отменить`).
5. **Админ-панель прямо в Telegram**:
   - Поддержка **нескольких администраторов** (`ADMIN_IDS`).
   - Заявка прилетает администраторам в Telegram с кнопками:
     `[ ✅ Подтвердить ]` `[ ❌ Отклонить ]`
   - При подтверждении или отклонении статус фиксируется в базе данных, заявка обновляется у администратора, а клиенту автоматически отправляется персонализированное уведомление.
   - Защита по списку `ADMIN_IDS` — только доверенные лица могут принимать решения.
6. **Надежное хранение данных (SQLite)**:
   - Все заявки сохраняются в базу данных (`data/bot.db`). При перезапуске бота данные и статусы не теряются.
7. **Кнопка «❌ Отменить»**: Доступна на каждом шаге диалога.
8. **Безопасность**:
   - Токен бота и ID админов хранятся исключительно в `.env`.

## ⚙️ Настройка конфигурации (`.env`)

Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Заполните ваши параметры:
```env
# Токен от @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Telegram ID администраторов (один или несколько через запятую)
# Узнать свой ID можно в боте @userinfobot
ADMIN_IDS=123456789,987654321

# Путь к файлу базы данных SQLite (по умолчанию data/bot.db)
DB_PATH=data/bot.db

# Контакты бизнеса (опционально, есть значения по умолчанию в config.py)
BUSINESS_ADDRESS=г. Киев, ул. Центральная, 10
BUSINESS_PHONE=+380 99 123 45 67
BUSINESS_SCHEDULE=Пн-Сб: 09:00 - 20:00, Вс: 10:00 - 18:00
```

## ▶️ Запуск

### Способ 1: В Docker (рекомендуется)

```bash
docker compose up -d --build
```

Посмотреть логи:
```bash
docker compose logs -f
```

---

### Способ 2: Локально через Python

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows (PowerShell):
   .\venv\Scripts\Activate.ps1
   # Linux / macOS:
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
