# 🤖 Telegram-бот для малого бизнеса (генератор заявок / лидов) — Node.js

Готовый и надежный Telegram-бот для малого бизнеса (салоны красоты, барбершопы, мастерские, консультации, клиники и др.).

Версия на **Node.js (Telegraf 4.x)**.

> 🐍 **Ищете версию на Python (aiogram 3.x)?** Она доступна в ветке [`main`](https://github.com/qavalliere/tgbot/tree/main).

---

## 🚀 Возможности

1. **Главное меню (`/start`)**:
   - `📋 Оставить заявку`
   - `💰 Услуги`
   - `📍 Контакты`
2. **Прайс-лист (`💰 Услуги`)**: Список услуг с ценами и кнопка быстрого перехода к заявке.
3. **Контакты (`📍 Контакты`)**: Адрес, телефон, график работы.
4. **Пошаговое оформление заявки (FSM / Сессии)**:
   - Шаг 1: Имя клиента.
   - Шаг 2: Номер телефона (ввод вручную или кнопка «📱 Поделиться контактом»).
   - Шаг 3: Выбор услуги (кнопки с услугами + «Другая услуга»).
   - Шаг 4: Желаемое время и дата.
   - Шаг 5: Проверка данных и подтверждение (`✅ Отправить` / `❌ Отменить`).
5. **Админ-панель прямо в Telegram**:
   - Заявка прилетает владельцу в Telegram с кнопками:
     `[ ✅ Подтвердить ]` `[ ❌ Отклонить ]`
   - При подтверждении или отклонении заявка обновляется у администратора, а клиенту автоматически отправляется персонализированное уведомление.
   - Защита по `ADMIN_ID` — только владелец может принимать решения.
6. **Кнопка «❌ Отменить»**: Доступна на каждом шаге диалога.
7. **Безопасность**:
   - Токен бота и ID админа хранятся исключительно в `.env`.

## ⚙️ Настройка конфигурации (`.env`)

Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Заполните ваши параметры:
```env
BOT_TOKEN=849...................
ADMIN_ID=8596............

BUSINESS_ADDRESS=г. Киев, ул. Центральная, 10
BUSINESS_PHONE=+380 99 123 45 67
BUSINESS_SCHEDULE=Пн-Сб: 09:00 - 20:00, Вс: 10:00 - 18:00
```

---

## ▶️ Запуск бота

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите бота:
   ```bash
   npm start
   # или: node bot.js
   ```
